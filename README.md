## Overview

**EduAssist AI** is a cloud-native, serverless student support platform that helps educational institutions automate responses to common academic enquiries.

Rather than relying solely on manual administrative support, students submit questions through a REST API and receive AI-generated answers within seconds. Every interaction is securely stored in Amazon DynamoDB, building a searchable knowledge base that can evolve into a full institutional FAQ system over time.

The platform is built on AWS serverless technologies and follows modern cloud engineering practices, including Infrastructure as Code, CI/CD automation, observability, security, and scalable architecture.

---

## Problem Statement

Educational institutions routinely field hundreds of repetitive academic questions about:

- Admissions
- Course registration
- Examination schedules
- Tuition payments
- Graduation requirements
- Academic policies
- Student services

Handling these manually typically results in:

- Slow response times
- High administrative workload
- Inconsistent answers
- No centralized knowledge repository

**EduAssist AI** solves these problems with an intelligent, scalable, and cost-effective automated support system.

## Solution

EduAssist AI provides:

- AI-generated academic responses

## Key Features

### AI-Powered Responses
Students submit academic questions through the API and receive intelligent, context-aware responses generated by an AI service.

### Serverless Architecture
The entire backend runs on AWS serverless services, eliminating server management while automatically scaling with demand.

### Knowledge Repository
Every question and answer is stored in DynamoDB, allowing institutions to build a reusable knowledge base over time.

### Frequently Asked Questions
Repeated questions are promoted into a centralized FAQ collection, reducing redundant AI requests and improving response times.

### Cloud Monitoring
Amazon CloudWatch provides:
- Execution logs
- Error tracking
- Performance metrics
- Operational insights

### CI/CD Pipeline
Every push to GitHub automatically:
- Runs linting
- Executes tests
- Packages Lambda functions
- Deploys to AWS

## API Reference

### Ask a Question
```http
POST /questions
```

**Request**
```json
{
  "question": "What are the admission requirements for Computer Science?"
}
```

**Response**
```json
{
  "id": "12345",
  "question": "What are the admission requirements for Computer Science?",
  "answer": "Admission requirements include..."
}
```

### Get All Questions
```http
GET /questions
```

### Get Question by ID
```http
GET /questions/{id}
```

### Delete Question
```http
DELETE /questions/{id}
```

### Get FAQs
```http
GET /faqs
```

## Database Design

**Table Name:** `StudentQuestions`

**Primary Key:** `questionId`

**Attributes:**

| Attribute      | Description                          |
|----------------|---------------------------------------|
| `questionId`   | Unique identifier for the question    |
| `studentId`    | Identifier of the submitting student  |
| `question`     | The submitted question text           |
| `answer`       | AI-generated response                 |
| `category`     | Topic classification                  |
| `timestamp`    | Time the question was submitted       |
| `status`       | Processing status                     |
| `responseTime` | Time taken to generate the response   |
| `aiModel`      | AI model used to generate the answer  |
| `feedback`     | Optional student feedback on answer   |

## Local Development

**1. Clone the repository**
```bash
git clone https://github.com/<organization>/eduassist-ai.git
```

**2. Navigate into the project**
```bash
cd eduassist-ai
```

**3. Create a virtual environment**
```bash
python -m venv .venv
```

**4. Activate it**

Linux / macOS:
```bash
source .venv/bin/activate
```

Windows:
```bash
.venv\Scripts\activate
```

**5. Install dependencies**
```bash
pip install -r requirements.txt
```

**6. Run tests**
```bash
pytest
```

## Branch Strategy

| Branch              | Purpose                                  |
|----------------------|-------------------------------------------|
| `main`               | Production-ready code                     |
| `develop`            | Integration branch for ongoing development|
| `feature/<name>`     | New features                               |
| `hotfix/<issue>`     | Urgent production fixes                    |
| `release/<version>`  | Release preparation                        |

All development happens on feature branches, merged into `develop` via pull requests. Production deployments are cut from `main`.
